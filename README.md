# pstr-whitebox

Реверс-инжиниринг двух строковых 
функций из состава QEMU (`pstrcpy`, `pstrcat`).

## Метод

1. **Исходная реализация** — эталонный код заимствуется без
   изменений из промышленного проекта (`original/`).
2. **Спецификация** — из эталонной реализации восстанавливается
   инвариантная спецификация на языке ACSL, не зависящая от
   конкретной реализации (`contract/`).
3. **Производная реализация** — разрабатывается независимо, с
   единственным требованием: удовлетворять восстановленной
   спецификации (`reversed/`).
4. **Верификация** — обе реализации доказываются против общей
   спецификации средствами Frama-C/WP (`verification/`).
5. *(перспектива)* **Математическая модель** — по спецификации обратно разрабатывается
   математическая модель, из которой затем выводится обратно новая спецификация (`docs/`).

## Структура

    original/      эталонная реализация (QEMU, GPL-2.0-or-later)
    contract/      спецификация (ACSL)
    reversed/      производная реализация
    verification/  сценарии верификации (Frama-C/WP)
    docs/          математическая модель (в разработке)
